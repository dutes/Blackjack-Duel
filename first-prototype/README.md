# First prototype (July 2025)

The very first playable version of Blackjack Duel: one HTML file, no server, no build step.

You play three hands against an AI that hits until 17, with one Redraw before play starts. Every move is written to a log on the right so the flow of a round can be checked step by step. Double and the hidden bust came later, in the [King of the Hill](../king-of-the-hill/) and 1v1 duel prototypes.

**▶ Play it live:** https://dutes.github.io/Blackjack-Duel/first-prototype/

Or open `index.html` in a browser.
